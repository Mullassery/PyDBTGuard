# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1, summarized:

- Be respectful and constructive in issues, PRs, and discussions.
- No harassment, personal attacks, or discriminatory language.
- Disagreements about code and design are fine and expected; keep them
  focused on the work.

Reports of unacceptable behavior can be sent to **mullassery@gmail.com**.
For the full text, see
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
